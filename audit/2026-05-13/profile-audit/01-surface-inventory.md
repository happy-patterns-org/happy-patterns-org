# Surface Inventory

Classification terms used here:

- `source-defined`: present in local source/config, not live-verified in this audit.
- `source-tested`: local source records prior test evidence, not rerun in this audit.
- `report-only`: emits evidence but is not treated as a blocking gate here.
- `required/blocking`: only used when local source plus current provider/ruleset evidence proves it. This audit did not perform provider verification, so current provider-required status is not asserted.
- `trace-blocked`: provider/live confirmation intentionally not performed under audit stop rules.
- `not observed`: no local surface found in this pass.
